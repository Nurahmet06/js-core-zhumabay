# JavaScript Core Project

**Student:** Zhumabay Nurahmet

## Project Description

This project demonstrates JavaScript fundamentals, including array methods, closures, classes, inheritance, and unit testing.

## Implemented Functions

- unique() - removes duplicate elements.
- groupBy() - groups array elements by a key.
- chunk() - splits an array into smaller arrays.
- deepClone() - creates a deep copy of objects.
- memoize() - caches function results.
- counter() - creates a counter using closures.

## Classes

### Store
A class for managing items with methods:
- add()
- remove()
- find()
- total()

Includes private fields, getters, and static methods.

### SortedStore
Extends Store and returns items sorted by name.
